# Glossary

- **Architecture:** the processor instruction-set and design family.
- **BIOS/UEFI:** firmware that initializes hardware and starts the operating system.
- **Chipset:** platform hardware that helps connect the processor to other components.
- **Device ID:** an identifier used to distinguish a hardware device.
- **GPU:** graphics processing unit.
- **Hardware ID:** an operating-system-readable identifier for a device.
- **Kext:** short for kernel extension; a macOS kernel-level software component. VenturaScope does not distribute or configure kexts.
- **PCI:** a standard family of interfaces for connecting internal devices.
- **Subsystem ID:** an identifier that can further distinguish a device or board implementation.
- **UEFI:** Unified Extensible Firmware Interface.
