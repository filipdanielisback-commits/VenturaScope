# Source Quality Standards

Prefer sources in this order:

1. Manufacturer product specifications and support documentation.
2. Official operating-system or standards documentation.
3. Peer-reviewed technical material or reproducible engineering documentation.
4. Reputable technical publications with clear methodology.
5. Community reports, clearly labeled as reports.

For every source, capture:
- Title or organization
- URL
- Publication or access date, where available
- Exact claim it supports
- Limitations or uncertainty

A source about one component must not be used to claim that an entire system is compatible.
