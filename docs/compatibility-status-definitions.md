# Compatibility Status Definitions

Use these labels consistently throughout the project.

| Status | Meaning |
|---|---|
| Documented | A reliable primary source confirms the specific technical fact. |
| Reported | A contributor or community source reports an observation. |
| Independently verified | Multiple independent, reproducible sources support the same observation. |
| Unknown | Evidence is missing, conflicting, or too weak. |
| Not applicable | The field does not apply. |

## Rules
1. Never infer full-system compatibility from a CPU or GPU name alone.
2. Record the exact model, revision, and hardware identifier when available.
3. Include source URLs and access dates for research claims.
4. Keep unverified reports clearly attributed.
5. Do not turn an unknown value into a guess.
