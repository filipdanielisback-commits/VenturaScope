# Frequently Asked Questions

## Does VenturaScope install macOS?
No. It is a hardware inventory and compatibility research project.

## Does a listed component guarantee that a computer is compatible?
No. Component-level information is only one part of a complete system assessment.

## Why are some entries marked unknown?
Because the project should not guess. Unknown means reliable evidence has not yet been collected.

## Can I submit my computer specifications?
Yes. Use the hardware report issue template and remove personal information first.
