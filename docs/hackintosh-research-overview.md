# Hackintosh Research Overview

VenturaScope documents hardware and macOS compatibility research for educational and historical reference.

## Scope
- Explain hardware components relevant to macOS compatibility.
- Record manufacturer specifications and credible technical sources.
- Separate verified facts, community reports, and unknowns.
- Track hardware identifiers without publishing personal identifiers.

## Important platform and licensing note
Apple's macOS license limits installation and use to Apple-branded computers. VenturaScope does not provide installation media, bootloader configurations, bypasses, or instructions for installing macOS on non-Apple hardware.

## Evidence labels
- **Documented:** supported by a primary manufacturer or official technical source.
- **Reported:** an attributed community or user report, not independently verified.
- **Unknown:** insufficient reliable evidence.
- **Not applicable:** the field does not apply to the device.

A component-level observation must never be presented as proof that an entire computer is compatible.
