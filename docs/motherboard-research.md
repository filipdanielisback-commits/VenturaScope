# Motherboard Research Guide

## Fields to collect
- System manufacturer and model
- Board manufacturer and exact board model
- Board revision, if printed or documented
- Chipset, with source
- Firmware vendor and version (do not publish serial numbers)
- Official product or support page

Prebuilt computers may use custom board identifiers. If Windows reports a placeholder such as “To be filled by O.E.M.”, record the exact observation and mark the board model unknown rather than guessing.
