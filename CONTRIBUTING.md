# Contributing to VenturaScope

Thanks for helping improve the research!

## Before opening a contribution

- Keep claims specific to exact hardware and macOS versions.
- Include direct source links for compatibility statements.
- Separate firsthand reports from independently verified facts.
- Use the status definitions in `docs/compatibility-methodology.md`.
- Never include serial numbers, account details, or other private information in reports or screenshots.

## Code contributions

The initial Windows inventory script should remain read-only. Avoid collecting identifiers that are not needed for hardware research, and explain any new data field in the pull request.

## Suggested report format

- Exact hardware model:
- macOS version/build discussed:
- What was tested:
- Result:
- Source links:
- Date checked:
- Known limitations:
