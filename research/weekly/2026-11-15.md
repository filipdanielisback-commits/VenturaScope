# Weekly compatibility research report — 2026-11-15

## Executive summary

No new independently verified Ventura 13 result was found for the exact Lenovo 1652K8G system or for its recorded Intel Pentium G630 and Intel HD Graphics adapter. The strongest new material is current, attributable project documentation describing Ventura's pre-Haswell CPU limitation, Sandy Bridge graphics limits, Intel Wi-Fi project support, AppleALC codec coverage, and the narrow scope of NVMeFix. These sources are useful research evidence, but they are not an exact-system test or Apple certification.

## Findings

| Area | Evidence and scope | VenturaScope status |
|---|---|---|
| Intel CPU — Pentium G630 | Intel's second-generation desktop processor datasheet includes the G630 in the Pentium G600 series. Dortania's current hardware guide states that Ventura drops support for pre-Haswell CPUs and that the guide no longer supports pre-Haswell CPUs on Ventura and newer. Dortania's Sandy Bridge desktop page lists macOS 12 Monterey as the last supported OS for that generation. | **Unknown** for an exact G630 test. The guide's pre-Haswell limitation is a strong project-documentation lead, not an Apple statement or test of this exact Lenovo system. |
| Intel GPU — Intel HD Graphics, Sandy Bridge | Intel's Windows graphics-driver index includes the G630 in the Intel HD Graphics group. Dortania's Sandy Bridge graphics guide lists High Sierra 10.13.6 as the highest supported OS for its Sandy Bridge 2XXX section and names HD 2000, HD 3000, and HD P3000. The recorded PCI ID `PCI\\VEN_8086&DEV_0102&SUBSYS_307C17AA&REV_09` is not individually named in that list. | **Unknown** for the exact PCI ID. Do not rename it HD 2000/3000 or infer Ventura support from the family name. |
| Motherboard | The Lenovo system model is 1652K8G, but Windows reports the board product as “To be filled by O.E.M.” The exact board model, chipset, revision, and firmware remain unknown. Dortania's general motherboard statement is not evidence for this specific board. | **Unknown** |
| Wi-Fi | OpenIntelWireless maintains an adapter compatibility list and directs readers to source files for exact PCI IDs. Its itlwm v2.2.0 release explicitly added macOS Ventura support and notes Handoff is disabled on Ventura. The Lenovo adapter is unidentified. | **Unknown** for this system. The release is a version-specific project lead, not proof for an unidentified card. |
| Audio | AppleALC's current supported-codec table is v1.9.8 (edited 2026-09-30) and lists codec revisions and layout IDs. Its notation `MinKernel 13 (10.9)` refers to the Darwin kernel version shown with macOS 10.9, not the Ventura marketing version 13. The Lenovo codec is unidentified. | **Unknown** |
| Storage | The profile only identifies Disk 0 as an HDD with a reported capacity of 465.75 GB. Exact drive model, interface, controller, and firmware are unknown. NVMeFix targets selected NVMe power-management and timeout issues; it is not a general SATA/HDD fix. | **Unknown** |
| Complete system | No Ventura point-release, firmware configuration, or reproducible whole-system test evidence is recorded for Lenovo 1652K8G. | **Unknown** |

- Standardized the project on exactly five labels: **Documented**, **Reported**, **Independently verified**, **Unknown**, and **Not applicable**. A documented limitation uses **Documented** with a precisely scoped claim; “Not supported” is not a separate status.
